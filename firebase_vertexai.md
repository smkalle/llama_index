
# Quick Start Guide: Gemini Integration in Flutter with Firebase AI Logic

This guide helps **startup app developers** integrate **Gemini**, Google's AI model, into **Flutter apps** using **Firebase AI Logic**, ensuring **production-ready AI features** with **security and scalability**.

---

## Prerequisites

Before you begin:

- **Dart version**: `>= 3.2.0`
- Familiarity with **Flutter** development
- Optional: **Google Cloud project** (required for Vertex AI Gemini API, which needs billing)

---

## Steps

### 1. Set Up Firebase Project

- Go to the [Firebase Console](https://console.firebase.google.com/)
- Create/select a project and add your Flutter app

### 2. Enable AI Logic

- Visit the [AI Logic page](https://console.firebase.google.com/project/_/ailogic)
- Choose one:
  - **Gemini Developer API** (no cost, Spark plan)
  - **Vertex AI Gemini API** (requires billing, Blaze plan)
- Enable the APIs and generate a Gemini API key (don't hardcode it!)

### 3. Install SDKs

```bash
flutter pub add firebase_core
flutter pub add firebase_ai
```

### 4. Initialize Firebase

Update your `lib/main.dart`:

```dart
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart'; // Generated by Firebase setup

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(options: DefaultFirebaseOptions.currentPlatform);
  runApp(MyApp());
}
```

### 5. Integrate Gemini

Add the Gemini logic:

```dart
import 'package:firebase_ai/firebase_ai.dart';

final model = FirebaseAI.googleAI().generativeModel(model: 'gemini-2.0-flash');
final response = await model.generateContent([
  Content.text('Write a story about a magic backpack.')
]);

print(response.text);
```

### 6. Run Your App

```bash
flutter run
```
